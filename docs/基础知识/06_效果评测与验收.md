## 33 Precision、Recall、F1、MRR、nDCG与安全指标

假设人工认为相关的证据是`{A,B,C}`，系统返回有序列表`[X,B,A]`，其中X无关。命中A、B共两条：

| 指标 | 怎么算 | 本例 | 回答的问题 |
|---|---|---|---|
| Precision | 命中的不同证据数 / 返回的不同证据数 | 2/3 | 找到的材料有多少相关 |
| Recall | 命中的不同证据数 / 应找到的证据数 | 2/3 | 相关材料覆盖多少 |
| F1 | 2 × Precision × Recall / 二者之和 | 2/3 | 精确与覆盖是否兼顾 |
| RR | 1 / 第一条相关结果的名次 | 1/2 | 有用材料能否尽早出现 |

MRR是多道题的RR平均，不是将所有查询拼成一个长列表再找第一条结果。nDCG评价整体排序：相关结果越靠前贡献越大；用实际DCG除以理想DCG得到归一化分数。项目用二元相关性，第r名相关结果的贡献为`1/log2(r+1)`。

项目按既定截断范围比较排序，理想相关数量最多取参考相关数量与实际返回数量的较小值。空列表、重复证据和零分母有明确约定，阅读公式后还要看实现的边界处理；不能只因为字段叫nDCG就假定所有系统细节相同。

宏平均先给每道题算指标，再取均值，每题权重相同。微平均则先汇总所有命中数和总数再算比例；二者在样本规模不等时可能不同。本项目相关评测主要保存逐题结果和宏平均。

**最小练习。**

```python
relevant = {"A", "B", "C"}
returned = ["X", "B", "A"]
hits = set(returned) & relevant
precision = len(hits) / len(set(returned))
recall = len(hits) / len(relevant)
f1 = 2 * precision * recall / (precision + recall)
assert round(f1, 4) == 0.6667
```

这段练习不处理空集合，仅用于理解命中、分母和调和平均。正式边界看[检索评测](../../app/modules/knowledge/application/evaluation.py)与[Agent评测](../../app/modules/operation_event/application/evaluation.py)。

Agent效果还比较类别和风险标签。风险低估率统计实际等级低于人工等级的比例；不安全建议率由人工判定统计。一个方案可以“不够完整但不危险”，所以建议可接受和不安全并不是简单互反。

运行时规则分检查字段、引用ID和复核过程；它不能证明原文支持结论。模型Critic属于同次模型判断，也不能代替人工安全标注。零危险率只说明当前已标注样本中没有发现，不代表未来绝无风险。

## 34 development、held_out、专家标注与闭环验收

development是用于分析问题、调参和提示词搜索的开发集；held_out是预留的独立验收集。如果反复查看留出集错误并据此调整，就会把验收信息带进开发过程，减弱泛化评价的意义。

专家标注提供参考类别、风险、相关证据，以及对具体建议的可接受和安全判断。结构校验只能检查标签格式，不能自动证明标注者具有业务资质。样本、标注理由和审核责任应明确。

```text
固定基线评测 → 人工确认问题和措施 → 实际实施修改
→ 用修改后的系统产生新调查/回答 → 人工标注新输出
→ 可比较的复测与前后指标 → 独立人员验收 → 保留历史
```

**基本使用。** 原运行重新打分只产生新评分，不等于重新执行修改后的系统。Agent复测应创建新的AgentRun，再用新结果建立评测；建议安全标签要针对新方案重新判断，不能沿用旧方案标签。

前后比较应保持事件版本、已确认观察修订及客观参考条件可比。引用ID随重建变化时，RAG可用文档编号与稳定引文作参照；Agent则检查新证据来自对应的新运行。资料本身发生实质变化时，应建立新基准，不能强算成同集提升。

本项目的`EvaluationImprovement`保存问题、措施、基线、目标、实施记录、复测和验收历史。目标达标不自动关闭，独立验收人还要判断；安全门槛不能用配置放宽。GEPA候选发布进一步要求开发与留出事件分离，以及复测确实使用该候选版本。

实现见[quality/service.py](../../app/modules/quality/application/service.py)，流程与接口见[第11章](../第11章_效果评测与改进验收闭环.md)。测试中使用Fake结果只能证明流程和约束，真实模型效果需要真实服务、代表性样本和人工标注。
