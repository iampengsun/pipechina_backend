# 首版整理验证

## MCP业务需求

支持外部助手提交待确认观察，使用用户、事件和request_id确定幂等记录；相同请求重试返回同一条，不同内容或版本冲突。待确认材料不进入事实上下文，确认仍使用原业务审核接口。读取工单验收上下文与知识变更复核事项时重新校验身份、权限和当前版本。

MCP共13个工具：12个只读、1个待确认材料提交；3类资源模板、2类提示模板。工单查询复用应用层实测记录服务。MCP绕过HTTP响应幂等缓存，防止业务或授权变化后重放旧内容；提交去重在业务事务中执行。
