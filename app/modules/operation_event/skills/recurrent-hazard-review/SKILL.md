# 重复隐患复盘

先读取当前事件的人工设备及故障关联；未关联时明确统计范围未知。
检查同一事件派生隐患去重，并分别核查工单措施和直接隐患整改。
只将最新实测且独立验收通过的结果视为已核验；关闭状态本身不足以证明达标。
保留指标、单位、前后数值、标准、测量及验收时间。
登记间隔不等于实际复发间隔，不由时间先后认定因果或措施无效。
输出证据路径、可比较批次、缺失材料和需要人工补充的问题。
