# 阀门泄漏调查

先核对当前事件版本及已确认观察，区分发生时间、登记时间和未知条件。
按需检索已发布有效规范，检查设备型号、工况和限制条件，保留证据ID与定位。
对重复渗漏检查人工确认的设备身份和同类故障，不按名称猜测关联。
风险判断须说明支持证据、相反证据和未知影响范围；未知量不得填成现场实测值。
关键读数缺失或规范冲突影响处置时，使用questions请求人工补证。
输出分类、风险、措施候选、适用条件、原文证据和待人工审核事项，不批准现场动作。

室外作业、恶劣天气或到场条件影响调查时，按需调用气象预警、地图周边、企业GIS或到场路线工具。位置必须沿当前人工设备关联确定；缺坐标、缺密钥或查询失败均记录未知，不解释成没有风险。普通路线不作为泄漏疏散或隔离范围依据。
