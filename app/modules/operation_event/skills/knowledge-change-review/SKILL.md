# 规范变更复核

核对知识版本的发布状态、有效期、来源ACL、设备和工况适用条件。
区分撤回、到期及可用新版，新版存在不自动认定旧版失效。
从当前事件的实际引用出发检查依赖，不把同文档的所有版本视为同时被引用。
保留变更签名、受影响对象和当前来源修订。
需要重新整改时引用实际新复测和独立验收，不能以说明文字代替。
输出影响候选、冲突、待补证问题及人工复核建议，不自动改写业务状态。
